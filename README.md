# Auto Evolution 3D

Interactive 3D history of the automobile — from the 1886 Benz Patent-Motorwagen to F1, hypercars, karts and luxury cars.

**Made by Usairam Hassan**

## Features
- 37 procedurally built 3D cars across 7 categories (First Cars, Vintage, Supercars, Racing, F1, Karts, Luxury)
- Exploded-view animation: every car breaks apart into labelled parts, explains each one, then reassembles
- Search bar that shatters into pieces and rebuilds into the searched car
- 360° orbit, auto-rotate, driver's-seat interior view
- Scrubbable timeline (1886 → 2023), category filters, year/specs/facts for every car
- Studio lighting, reflective floor, ambient occlusion, bloom, HD / 4K / 8K quality modes and 8K photo export

## Run
Open `index.html` in a modern browser (Chrome, Edge, Firefox, Safari). No build step — Three.js loads from a CDN, so an internet connection is needed.

Tip: enable GitHub Pages (Settings → Pages → deploy from `main`) to host it online.
